# Feedback & Contributions

We value your input! Here's how you can share feedback, report issues, or contribute to AgentMesh.

## 🐛 Report a Bug

If you find a bug, please [open a GitHub Issue](https://github.com/wangxianjiangwxj-ctrl/agentmesh/issues/new?template=bug_report.md) with:

- A clear title and description
- Steps to reproduce (minimal code snippet preferred)
- Expected vs actual behavior
- Environment: Python version, OS, AgentMesh version (`pip show agentmesh`)

## ✨ Request a Feature

Feature requests are welcome via [GitHub Issues](https://github.com/wangxianjiangwxj-ctrl/agentmesh/issues/new?template=feature_request.md).

When requesting, include:

- **What problem** are you trying to solve?
- **What solution** would you like to see?
- Have you considered any **workarounds or alternatives**?

## 💬 Start a Discussion

For questions, ideas, or general conversation:

- [GitHub Discussions](https://github.com/wangxianjiangwxj-ctrl/agentmesh/discussions) — best for open-ended topics
- Open an Issue for concrete proposals

## 🤝 Contribute Code

See [CONTRIBUTING.md](https://github.com/wangxianjiangwxj-ctrl/agentmesh/blob/main/CONTRIBUTING.md) for:

- Development setup
- Coding standards (ruff, type annotations)
- Test requirements (pytest, 80%+ coverage preferred)
- PR workflow
